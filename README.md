## 启程 · 求职教练

面向计算机及工科学生的本地求职智能体：先明确目标岗位，再基于本人提供的材料整理简历、准备面试、推荐适配岗位、记录投递和导出求职材料。使用本机 Ollama `qwen3:1.7b`。

项目成员：叶易初（f25011538）、苏靖棋（f25011531）。

- [智能体源码与完整说明](job-coach/README.md)
- [下载源码包（含 PPT，不含模型和个人数据）](downloads/job-coach-agent.zip)
- [期末汇报 PPT（12 页）](presentations/启程-求职教练-期末汇报-叶易初-苏靖棋.pptx)
- [HTML 汇报源码](job-coach/presentation.html)
- [原有个人网页](mumusjq.html)

Windows 安装 Python 3.11+、Ollama 并准备好 `qwen3:1.7b` 后，进入 `job-coach` 目录双击 `start.bat`，浏览器会打开本机工作台；结束时双击 `stop.bat`。文本型 PDF 的可选解析依赖和其他启动方式见完整说明。

仓库用于交付源码与汇报文件，上传 GitHub 不会自动运行 Python 服务或本地模型。推荐分数是材料证据适配度，不代表录取概率；示例档案为虚构数据。私有配置、简历、聊天记录、临时分享邀请码和模型权重不包含在提交中。
