# 启程 · 求职教练

面向计算机及工科学生的双人期末项目，采用**路径 B：普通求职管理应用 + 智能体工具调用**。先明确目标岗位，再用用户提供的简历、项目材料和岗位 JD 完成匹配分析、简历整理、面试练习、投递台账与材料导出。

项目成员：**叶易初，f25011538；苏靖棋，f25011531**。封面信息不进入简历样例。课堂演示使用独立的虚构档案，不能当作本人经历。

## 功能与技术

| 环节 | 业务功能 |
|---|---|
| 明确目标 | 保存岗位、求职阶段、城市与背景，缺少岗位时先询问 |
| 整理材料 | 粘贴文本，导入 TXT、MD、DOCX、文本型 PDF，检索本地来源片段 |
| 岗位匹配 | 对照 JD 的显式技能，展示个人材料证据、缺口和优先修改项 |
| 公司与岗位推荐 | 技能证据画像、手动岗位公司库、适配排序、公司资料对照、差距补齐与清单 |
| 简历整理 | 生成有来源的正文与 STAR 提纲，缺失内容标【需确认】 |
| 面试练习 | 生成练习题，逐题保存答案、表达评分与反馈 |
| 投递跟踪 | 公司、岗位、链接、状态、截止日期，人工确认后保存台账 |
| 材料复用 | 简历 HTML/Markdown、面试清单、匹配建议、投递 CSV 与 ZIP |
| 推荐清单 | 公司、岗位、适配分、理由、链接与截止日期，导出 CSV / Excel |

**匹配分数和推荐分数都不是录用概率。**原单份 JD 匹配计算显式技能覆盖率；推荐引擎在可识别要求范围内区分同义匹配与相关技术部分匹配。未匹配到证据不等于用户不会该技能。面试分数用于辅助检查表达与证据完整度，不代表招聘方评价，也不验证所有技术答案。

- 模型：本机 Ollama，默认 `qwen3:1.7b`，OpenAI 兼容 Chat Completions 接口。
- Agent：Python 自建轻量循环，模型返回真实 `tool_calls`，服务端执行工具白名单。
- 界面：HTML/CSS/JavaScript + Python HTTP 服务，无外部 CDN。
- 数据：SQLite 保存档案、材料、对话、练习、台账和导出记录，按会话隔离。
- 解析：DOCX 使用 ZIP/XML，文本型 PDF 使用 `pypdf`；扫描 PDF 需用户提供可提取文字。
- 检索：本地文本检索、技能词表、同义词和相关技术关系，不使用向量数据库，不夸称为通用语义 RAG。
- 不使用 LangChain、LangGraph、MCP 或 Agent Skills。产品能力模块不等于 `SKILL.md` 规范的技能包。

模型决定调用哪些工具及其参数。一条工具调用也可以组合多个业务操作，例如匹配工具收到导出参数后，依次分析当前档案并生成材料包；界面如实显示这一条实际调用，不把内部操作冒充多个模型调用。独立的简历与导出工具仍可单独使用。来源过滤、匹配口径、简历事实边界、确认事务和文件生成由业务代码执行。简历采用保守的事实整理与模板表达，避免小模型自由改写时添造经历。未调用工具时只展示流程引导，不直接采用模型自由编写的履历文本。模型仍可能误解意图，需查看执行记录并核对输出。

## Windows 启动

要求 Windows 10/11、Python 3.11 或以上、Ollama、Edge 或 Chrome。项目目录沿用 `campus-volunteer-agent`，产品已改为求职教练。

日常启动不联网安装依赖，也不下载模型。首次需要导入文本型 PDF 时，在项目目录打开 PowerShell，手动安装小型解析库（已经安装则跳过）：

```powershell
python -m pip install --target runtime/deps -r requirements.txt
ollama list
```

已有 `qwen3:1.7b` 就直接使用，无需重下。仅在缺少时运行 `ollama pull qwen3:1.7b`。

**日常使用：双击 `start.bat`，页面就绪后自动打开 http://127.0.0.1:8501。**服务在后台运行，不需要保留命令窗口。再次双击会复用本项目已有服务；模型在后台准备，本机页面不等待公网隧道。也可运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

**关闭本机版：双击 `stop.bat`。**关闭脚本核验启动记录与进程身份，只停止由本机启动器启动的进程；不会停止原先已运行的 Ollama，也不会在临时分享仍使用模型时将其关闭。临时分享需另用 `stop-share.bat` 关闭。启动日志和进程记录保存在忽略提交的 `runtime/` 下，关闭不会删除档案或材料。

已有 `.env` 会保留。手动启动时，可先复制 `.env.example` 为 `.env`，再执行 `python server.py`，使用 Ctrl+C 结束该手动进程。不要覆盖已有个人配置。端口占用时运行 `python server.py --port 8502`，并访问对应端口。

后台预热能减少启动后第一次对话加载模型的等待；实际生成速度仍取决于电脑性能和问题长度。公网分享需要另行建立隧道及等待 DNS/TLS 就绪，不能保证与本机启动一样快。

默认配置：

```dotenv
MODEL_BASE_URL=http://127.0.0.1:11434/v1
MODEL_NAME=qwen3:1.7b
MODEL_API_KEY=ollama
MODEL_TIMEOUT=120
```

`ollama` 是本地接口占位值，不是云端密钥。模型权重不放入仓库。本项目继续使用轻量 Qwen3 1.7B，不下载新模型；启动脚本为本机服务设置 8192 的默认上下文长度。

## 首次使用

### 临时分享给一位同学

Windows 本机已配好分享组件时，双击 `start-share.bat`，等待生成完整邀请链接，私下发给同学。无需输入口令：首次点击“进入体验”的浏览器获得唯一名额；只是打开或预览链接不会占用。同学应一直使用该浏览器并保留 Cookie，退出后可点“继续体验”。清除 Cookie 或换浏览器需要停止并重新创建分享。它限制浏览器凭据，不能核验真实身份，也不能防止使用者主动复制 Cookie。

分享期间电脑要保持开机联网、避免睡眠。启动后最多六小时自动关闭；提前关闭可双击 `stop-share.bat`。再次启动会创建新邀请和空白体验档案。邀请信息保存在本机 `runtime/share-*/share-info.json`，不要提交该目录或公开链接。

分享使用 `share_host.py` 启动独立数据目录、仅监听回环地址的源站和入口，以及 Cloudflare 临时 HTTPS 隧道。原 `runtime/career/` 不向同学开放；对方上传的资料保存在提供链接的电脑，建议使用示例或脱敏材料。入口检查登录、档案与下载归属，并限制请求频率、模型并发和材料容量。公网访问仍有剩余风险，适用于短时演示。

分享入口需要 Python、已有的本地 Qwen3 1.7B，以及 `runtime/tools/cloudflared.exe`。此副本固定校验已准备的 2026.10.5 Windows 版本；源码仓库不包含该二进制或模型。普通本机启动不依赖它。查看状态：`python share_host.py --status`；隐藏运行：`python share_host.py --background`（完整邀请从本次私有 `share-info.json` 读取）。

### 求职工作台

1. 填写目标岗位，例如“Python 后端实习生”。没有目标时先完成此步骤。
2. 添加简历初稿、项目材料及岗位 JD，选择正确资料类别。JD 和优秀范例不能成为个人经历证明。
3. 检查“岗位匹配”的证据与缺失项，再在“简历工作室”生成正文和 STAR。
4. 在“模拟面试”逐题练习，用“投递看板”记录个人进度。
5. 导出材料包，补齐【需确认】内容并本人核对后，再用于真实求职。

课堂演示可点“体验示例”。示例与真实档案分开，不把示例经历混入真实简历。回到真实档案后再添加自己的材料。

支持粘贴文本及单个不超过 5 MB 的 TXT、MD、DOCX、PDF。旧版 DOC、图片和扫描型 PDF 不直接识别。失败时可复制文字粘贴，不执行文档宏或外部链接。

## 公司/岗位适配推荐引擎

在“公司/岗位推荐”工作区录入公司、岗位 JD、公司介绍、资料来源、投递链接和截止日期。可以手动粘贴公开招聘内容；系统不自动抓取 Boss 直聘、拉勾、猎聘，也不会根据公司名字猜测技术栈、文化或招聘状态。

1. 添加简历、项目、技能清单、证书或作品集文本，生成个人技能画像。每个标签显示材料名称与原文片段，岗位 JD 和范例不充当个人经历。
2. 维护自己的岗位库，点击推荐。技能同义词可归一化，相关技术只计部分匹配。例如材料只有 Spring 经历时，不能据此宣称已经掌握 Spring Boot。
3. 对照匹配证据、缺失要求和公司适配依据。雷达图展示材料证据覆盖，不能衡量沟通或管理能力的真实水平；公司文化资料不足时标记需确认。
4. 按差距建议学习或完成真实项目，将新增证据加入材料后重新匹配。不能只勾选“学会了”就凭空增加能力。
5. 导出 CSV / Excel 推荐清单。清单用于安排准备和投递顺序，不会向企业发送材料；岗位是否仍开放、截止日期及链接仍需本人核实。

推荐只针对当前已录入的岗位库。未识别要求会保留为人工核对项，缺少可评分依据时不伪造分数。过期岗位默认不参与推荐。课堂示例公司与岗位均为虚构数据，真实档案不会自动加入示例岗位。

评分口径：常规要求权重 2，优先或加分要求权重 1；直接或同义匹配计完整权重，明确的相关技术关系只计部分权重。例如 Spring 与 Spring Boot 的相关迁移计 50%，该项仍有补齐建议。分母仅包含规则能够识别的技能要求，学历、经验年限及未知技术等需另行核对，因此高分不代表满足全部 JD。缺少个人技能证据或无法识别岗位要求时不输出分数。

画像包含技术能力、工具实践、沟通协作、项目管理、行业知识五个维度。每个维度显示支持词表中的证据标签覆盖比例；没有证据的维度标为未评估。这一比例描述材料，不能推断熟练程度或现实能力高低。

## 演示话术

先进入“体验示例”，或准备目标、个人材料和 JD。

1. “根据我的简历和岗位 JD 分析匹配度，列出三个优先修改点。”
2. “把项目经历整理成 STAR，并导出简历材料。”
3. “按目标岗位准备 10 道面试题。”
4. “记录一条本地投递：公司是示例科技，岗位是 Python 后端实习生，状态是待投递。”随后由本人检查并点击确认。
5. “列出本周截止的事项，并导出投递记录表。”

多步主路径：“分析我与目标岗位的匹配度，再生成简历并导出材料包。”展开工具执行记录，查看模型调用、服务端组合操作与真实下载链接。该任务可通过一次带导出参数的匹配工具完成，也可以通过多次调用完成，不要求固定调用次数。

## 真实性、隐私和权限

- 个人事实只来自简历、项目、成绩单、技能清单、证书和作品集材料。JD、题库、校招通知、范例不充当本人经历。
- 未提供的姓名、贡献、成果、时间或数据标【需确认】，不补写虚构获奖、实习或成绩。
- 匹配与能力映射保留材料名称和原文片段。“使用 AI 工具”不能推断为“具备模型训练经验”。
- 面试准备好题目后等待本人作答。答案评分只使用本轮用户实际输入，不允许模型替用户编写答案再评分。
- 投递新增和状态修改必须人工确认。模型没有确认工具，不向企业提交表单或发送邮件。
- 截止事项来自本地台账和导入通知，不自动抓取招聘网站。不完整或相对日期需人工确认。
- 数据保存在 `runtime/career/`，不进入 Git。不要提交真实简历、聊天记录、导出文件或 `.env`。
- 服务只绑定 `127.0.0.1`。会话隔离与 CSRF 不等于正式账号认证，当前面向本机单用户教学。
- 默认请求发送到本机。若自行切换云端接口，对话及工具结果会发给配置的服务。

## 代码入口

```text
server.py                 HTTP 接口、确认入口与下载校验
career/agent.py           模型协议、工具声明、白名单、多轮循环
career/service.py         目标、证据分析、简历、面试、台账、导出
career/recommendations.py  技能画像、技术关系、推荐评分与清单格式
career/documents.py       文件文本解析与输入限制
static/index.html         求职工作台、对话、执行记录和确认界面
tests/                    业务与协议测试
presentation.html         12 页离线课程汇报
docs/                     要求对照、答辩与验证方法
runtime/career/            本地私有数据与导出文件（不提交）
```

运行测试：`python -m unittest discover -s tests -v`。2026-10-27 验收通过 **38 项单元测试**（业务 19 项、Agent 19 项）、**7 个真实 Qwen3 1.7B 场景**及 **24 项网页集成检查**，浏览器 JavaScript 错误为 0。已验证来源与缺失项、面试评分、投递确认和修改、六文件导出、下载隔离、刷新保存、示例隔离及桌面/手机布局；具体范围见 `docs/TESTING.md`。

模型不在线时普通业务界面仍可使用。聊天连接失败先检查 Ollama 与 `ollama list`，不要把无工具的完成声明当作执行成功。通过这些样例检查不保证模型在任意新输入下都能正确选择工具。
