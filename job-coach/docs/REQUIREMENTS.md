# 期末要求对照

项目：启程 · 求职教练。双人项目，成员为叶易初（f25011538）、苏靖棋（f25011531）。选择路径 B。

来源：[《期末考查要求》](https://gitcode.com/nicezack/ai-opensource-practice-course/blob/main/期末考查要求.md)，本地读取提交 `31a11a8c5cf1d2602eb2396dc6f766dbefd7e61e`。下表为实现对照，不代替教师验收。

| 要求 | 对应实现 | 现场查看 |
|---|---|---|
| 正当校园场景 | 就业与生涯方向，求职准备 | 目标与材料 |
| 至少三个业务操作 | 目标、检索、匹配、推荐、简历、面试、台账、导出 | `career/service.py`、`career/recommendations.py` |
| 真实 Tool Calling | Qwen3 返回调用，白名单执行并回传 | `career/agent.py`、执行记录 |
| 一句话多步操作 | 匹配工具可组合分析与导出，亦可分别调用 | 实际工具记录与文件下载 |
| 确认或权限控制 | 台账变更先准备，模型没有确认工具 | 待确认区、HTTP 接口 |
| 独立普通应用 | 页面按钮共用业务函数 | 工作台各页面 |
| 多轮保存 | 材料、会话、答案和台账持久化 | 刷新后回载 |
| 明确产出 | 简历 HTML/MD、匹配建议、面试清单、CSV、ZIP、推荐 Excel | 材料包与公司/岗位推荐 |
| 来源和事实边界 | 个人材料与 JD/范例分区，证据引用 | 匹配与简历 |
| 仓库说明与环境 | README、依赖、配置示例、一键启动 | 根目录 |
| 8～12 页 HTML | `presentation.html` 共 12 页 | 离线打开 |
| 参考与 AI 披露 | 课堂参考及 Codex 辅助范围 | README、汇报第 10 页 |

一句话多步骤不等于多次模型调用：模型可在匹配工具中选择导出材料包，由业务层组合执行，并如实保留一次调用的记录。

匹配与推荐分数只反映可识别要求和当前材料证据的适配，不预测录用概率。推荐引擎使用同义词及相关技术的部分匹配，未使用通用向量语义检索，也不自动抓取招聘网站。STAR 未提供的贡献或成果标【需确认】。面试分数只辅助检查表达与证据完整度。推荐清单和投递台账不代表企业已收到简历。

提交前本人仍需：完整演示一次；理解 Agent、证据分析和确认事务；确认教师接受的平台及汇报场次；按指定方式提交仓库与 HTML；完成约 4 分钟汇报和 4 分钟现场演示。可另备不超过 3 分钟的录屏。程序生成或启动不代表这些动作已完成。
