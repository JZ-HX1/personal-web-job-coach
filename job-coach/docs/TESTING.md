# 验证方法与证据边界

业务单元测试、真实模型调用和人工界面检查分别记录。单元测试通过不证明小模型每次都能选对工具，也不证明匹配分数能预测录用。

## 自动测试

在项目目录执行：

```powershell
python -m unittest discover -s tests -v
```

| 场景 | 应有结果 |
|---|---|
| 目标或材料不足 | 提示先补充目标、简历/项目或 JD |
| JD/范例含优秀经历 | 不写入本人简历，不当作本人技能证据 |
| 个人材料没有成果数字 | 标【需确认】，不补造提升比例 |
| 跨档案读取 | 拒绝访问他人材料、台账或导出文件 |
| 示例与真实混写 | 阻止并引导回到真实档案 |
| 台账未经确认 | 正式记录不变化 |
| 跨会话、重复、过期确认 | 拒绝无效操作，避免重复写入 |
| 文件解析失败或超限 | 可解释错误，不执行文档内容 |
| CSV 公式起始字符 | 转义，避免表格软件执行公式 |
| 用户文本含 HTML | 显示和导出转义，不执行脚本 |
| 模型非法工具或字段 | 白名单与参数检查拒绝 |

## 真实模型检查

记录真实调用、参数与结果，不把模型的完成声明当作执行成功。

## 界面和产物检查

刷新后档案回载；示例不混入真实材料；证据、STAR、答案、确认单和链接可查看；桌面与窄屏无关键区域溢出；下载的 HTML/MD/CSV/ZIP 内容及档案归属正确；【需确认】保持可见。

汇报 HTML 为 10 页，离线打开，方向键翻页，N 显示讲稿，F 全屏。
